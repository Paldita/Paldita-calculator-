# Overview

Paldita Calculator is a modern open-source calculator built using Angular. It combines a clean glassmorphism interface with powerful calculation capabilities to deliver a fast, intuitive and responsive experience across desktop and mobile devices.

Designed with performance, accessibility and user experience in mind, it provides both standard and scientific operations while maintaining a beautiful, minimal interface.
